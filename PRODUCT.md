## Platform

## Stack

React 19, TypeScript, Vite 6, Tailwind CSS v4, Spring Boot 3.3, Spring AI 1.0 (MCP), Neon Serverless Postgres (PgVector HNSW), Phosphor Icons

## Users

AI engineers, prompt crafters, research students, and ML developers who build, iterate, and benchmark LLM prompts, tool invocations, and vector RAG retrieval with sub-second feedback loops.

## Product Purpose

Fox.ai (TeachMe AI) is a precision AI Prompt Studio and PgVector Knowledge Laboratory designed to eliminate latency and cognitive friction from prompt engineering and retrieval-augmented learning. It provides instant model switching across OpenAI, Anthropic, Gemini, and DeepSeek, hardware-style parameter synthesis, and scale-to-zero serverless vector search.

## Positioning

Unlike bloated enterprise chat wrappers and generic AI toys, Fox.ai provides a hardware-inspired synthesizer control surface, instantaneous multi-model hot-swapping, true reactive SSE byte streaming, and a zero-cold-start Neon PgVector database pipeline.

## Key Capabilities

- **Real-Time Synthesizer Control**: Tactile sliders with gradient feedback for Temperature, Top-P, Max Tokens, Frequency/Presence penalties, and prompt blueprint presets.
- **PgVector Knowledge Lab**: Local & serverless document ingestion with 1536-dimensional HNSW cosine similarity, automated pedagogical quiz generation, 3D flashcards, and Cornell notes.
- **Multi-Model Mesh**: Seamless failover and comparison across GPT-4o, Claude 3.5 Sonnet, Gemini 2.0 Flash, and DeepSeek-R1.
- **Prompt Blueprints Engine**: Searchable, categorizable prompt templates with variable injection and direct execution.
- **High-Craft Landing & Telemetry**: Live interactive terminal emulator with real-time token streaming and architecture benchmarks.
